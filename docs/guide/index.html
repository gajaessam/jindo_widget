진도 위젯 사용 설명서

반별 캐릭터가 수업 진도만큼 바탕 화면 위를 걸어가요. 이것만 알면 돼요.

1설치

관리자 권한 없이 설치돼요. 예전 버전을 쓰고 있었다면 그대로 덮어써지고 진도도 이어져요. 새 버전이 나오면 진도 위젯이 알려 드려요.

2기본 사용법

캐릭터 왼쪽 클릭그 반 진도창이 열려요. 활동을 체크하면 캐릭터가 앞으로 걸어가요.
캐릭터 오른쪽 클릭메뉴가 열려요. 설정, 백업 복원, 자동 실행, 종료가 있어요.
"+" 모양 누르기그 반 캐릭터 이미지를 골라요. (투명 배경 PNG 추천)
캐릭터 끌기잠깐 옮길 수 있어요. 놓으면 제자리로 돌아가요.

진도창에서는 ‹ › 로 차시를 넘기고, ⋯로 활동을 고치거나 지우고, + 활동 / + 차시로 추가해요. 실수했으면 ↶ 되돌리기. 모든 내용은 자동 저장돼요.

차시와 활동은 모든 반이 함께 써요. 체크와 메모만 반마다 따로예요.

3설정 (오른쪽 클릭 메뉴)

  • 반 · 캐릭터 설정: 반 개수와 이름, 캐릭터 이미지·크기, 대기 동작
  • 수업 계획 설정: 차시·활동을 한 화면에서 고치기. ⠿를 끌어서 순서 바꾸기
  • 백업에서 복원: 하루 한 번 자동으로 남는 백업으로 되돌리기
  • 자동 실행: 켜 두면 컴퓨터를 켤 때 저절로 실행
  • 전체 종료: 끄기 (Ctrl+Shift+Q도 돼요)

4꼭 알아 두세요

  • 캐릭터 그림은 사용할 권리가 있는 이미지만 골라 주세요. 진도 위젯에는 캐릭터 그림이 들어 있지 않아요.
  • 진도·메모·이미지는 이 PC(%APPDATA%\UsagiJindo)에만 저장되고 밖으로 보내지 않아요.
  • 새 버전이 나오면 알려 드려요. 내려받기를 눌러야만 받아요.

5이럴 땐

  • 캐릭터가 안 보여요 → 다른 창 아래에 있어요. 창을 내리거나 바탕 화면을 보세요.
  • "+"만 보여요 → 이미지 파일을 찾을 수 없어요. "+"를 눌러 다시 고르세요.
  • "저장 오류"가 떠요 → 디스크 공간을 확인하고 진도 위젯을 껐다 켜 보세요.
  • 다른 PC로 옮기기 → 진도 위젯을 끄고 %APPDATA%\UsagiJindo 폴더를 새 PC의 같은 자리에 복사하세요.
  • 프로그램을 지워도 진도 데이터는 남아요.
